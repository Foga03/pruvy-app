# pruvy-app

Pagine di avvio delle app interne PRUVY. Servono solo a dare a ogni app la sua icona nella schermata Home del telefono: le app vere restano su Google Apps Script, protette dall'accesso Google.

- `calendari/`: Calendari PRUVY (collaboratore)
- `calendari/simone/`: Calendari PRUVY (Simone, account info@pruvytech.com)
- `mondo/`: Mondo PRUVY

Aperta nel browser, ogni pagina spiega come aggiungerla alla Home. Aperta dall'icona, apre subito l'app.
